Bonkverse API terms

Version {{ terms_version }}. You agree to these when you create an API key.

Using the data

  1. Show where the data came from: "Levels from Bonkverse", with a link to the player's profile (profile_url) where you can.
  2. Don't resell the data, and don't republish it as a bulk dataset or a copy of Bonkverse.
  3. Respect players' choices. A player marked private has hidden their level; stop showing it at your next sync.
  4. Label times honestly. seen_at is when a replay showed the level, not when the player levelled up or was last online.

Your keys

  1. Keep your key secret: call the API from your server or bot, never from code that runs in someone's browser. If a key leaks, revoke it and make a new one.
  2. One key per site or bot. Don't spread requests over several keys to get around the rate limits.
  3. Keys can be revoked if they're used against these terms or in a way that strains Bonkverse. We'll try to reach you first.

What we promise

  1. The API is free and provided as is. Bonkverse is a fan project: it can be slow or down, and the data is only as complete as the replays we've collected.
  2. Within /api/v1/ we only add fields; we don't rename or remove them. Breaking changes get a new version.
  3. If these terms change, you'll be asked to agree again before your next new key. Your existing keys keep working.

Bonkverse's Terms of Service and Privacy Policy also apply. Bonkverse is not affiliated with bonk.io.
