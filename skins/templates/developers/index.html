Bonkverse API

Endpoints

Every endpoint is under https://bonkverse.io/api/v1/ and needs an API key.

EndpointWhat you get
GET/players/{username}/ A player's level, peak level, when it was last seen, games played, and their bonk.io account ID and join date
POST/lookup/players/ Up to 250 players in one request, for leaderboards
GET/players/{username}/level-history/ Every level-up seen in their replays, and their level on each day they played
GET/me/ The key you're using, to check it works

Your first request

  1. Get a key

    Make one with your bonk.io account. It's free and takes a minute.

  2. Keep it out of your code

    Put it in an environment variable on your server, never in a file you commit or in code that runs in someone's browser.

    Terminal 
    export BONKVERSE_API_KEY="paste your key here"

  3. Look up a player

    Terminal 
    curl https://bonkverse.io/api/v1/players/comet/ \
  -H "Authorization: Bearer $BONKVERSE_API_KEY"
    Node 18 or newer 
    const name = "comet";
const res = await fetch(
  `https://bonkverse.io/api/v1/players/${encodeURIComponent(name)}/`,
  { headers: { Authorization: `Bearer ${process.env.BONKVERSE_API_KEY}` } },
);
const body = await res.json();
if (body.ok) console.log(body.data.username, body.data.level?.value);
else console.log("error:", body.error);
    Python 3 with requests 
    import os
from urllib.parse import quote

import requests

name = "comet"
res = requests.get(
    f"https://bonkverse.io/api/v1/players/{quote(name, safe='')}/",
    headers={"Authorization": f"Bearer {os.environ['BONKVERSE_API_KEY']}"},
    timeout=10,
)
body = res.json()
print(body["data"] if body["ok"] else body["error"])

The response

Every reply has ok. When it's true the answer is in data; when it's false, error says what went wrong (all errors).

200 OK · JSON 
{
  "ok": true,
  "data": {
    "requested": "comet",
    "username": "Comet",
    "status": "found",
    "level": {
      "value": 87,
      "peak": 87,
      "seen_at": "2026-11-08T03:00:00.000Z",
      "seen_day": "2026-11-08",
      "estimated": false
    },
    "games": 120,
    "account": { "dbid": 9876543, "joined": "2019-06-02", "joined_estimated": true },
    "profile_url": "https://bonkverse.io/player/Comet/"
  }
}

Shortened; the player endpoint lists every field. seen_at is when the level was last seen in a replay, not when the player was last online.

Limits and fair use

KeyRequests a minuteBulk lookups a minute
Standard (made here)6010
Partner (ask us)30030
  • Credit Bonkverse, and link each player to their Bonkverse profile (profile_url).
  • Players who hide their level on Bonkverse stay hidden in the API too.
  • Going over a limit gets a 429 with retry_after: wait that many seconds.
